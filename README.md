# MIA desktop app — releases

Installers for the MIA build of AionUi. Binaries only; the source lives in a
private repository.

Downloads are on the [Releases](../../releases) page.

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `AionUi-<version>-mac-arm64.dmg` |
| Windows | `AionUi-<version>-win-x64.exe` |

The `.zip` and `latest-*.yml` files beside them are what the in-app updater
reads. They are not meant to be downloaded by hand.

Signing in requires a MIA account — the app cannot be used without one.
